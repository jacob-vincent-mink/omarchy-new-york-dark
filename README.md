# Omarchy New York Dark

A dark Omarchy theme for New York after sunset: Joseph Pennell’s harbor watercolor, a searchlit skyline, and Broadway in the 1920s. Smoky indigo and warm gold carry the palette.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-new-york-dark.git`, then run `omarchy theme set new-york-dark`. Cycle the four wallpapers with `omarchy theme bg next`.

For the companion theme, see [Omarchy New York Light](https://github.com/jacob-vincent-mink/omarchy-new-york-light).
