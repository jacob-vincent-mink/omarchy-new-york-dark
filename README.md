# Omarchy New York Dark

A 1921 New York harbor watercolor in smoky indigo and warm gold.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-new-york-dark.git`, then run `omarchy theme set new-york-dark`.

For the companion theme, see [Omarchy New York Light](https://github.com/jacob-vincent-mink/omarchy-new-york-light).
